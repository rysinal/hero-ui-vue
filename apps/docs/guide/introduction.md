# Introduction

HeroUI Vue is a modern, accessible Vue 3 component library built with Tailwind CSS. It provides a comprehensive set of UI components that are easy to use, customize, and integrate into your Vue applications.

## Features

- **Vue 3 Composition API**: Built from the ground up with Vue 3 and the Composition API
- **Accessible**: Built on Radix Vue primitives, ensuring WCAG compliance
- **Customizable**: Styled with Tailwind CSS for easy theming and customization
- **TypeScript**: Full TypeScript support with comprehensive type definitions
- **Dark Mode**: Built-in dark mode support
- **Tree-shakeable**: Import only the components you need

## Philosophy

HeroUI Vue follows these core principles:

1. **Accessibility First**: Every component is built with accessibility in mind
2. **Developer Experience**: Simple, intuitive APIs that are easy to learn and use
3. **Customization**: Flexible styling system that adapts to your design needs
4. **Performance**: Optimized for speed and minimal bundle size
