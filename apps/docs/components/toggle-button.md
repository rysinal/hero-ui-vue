# Toggle Button

Pressable toggle control.

## Import

```ts
import { ToggleButton } from '@heroui-vue/vue'
```

## Usage

:::preview

demo-preview=../demos/toggle-button-basic.vue

:::

## API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `selected` | `boolean` | `undefined` | Controlled selected state |
| `defaultSelected` | `boolean` | `false` | Initial selected state |
| `variant` | `'default' \| 'ghost'` | `'default'` | Visual style |
